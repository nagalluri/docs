On Windows, use **Ctrl** wherever the Mac uses **Cmd**, and **Alt** wherever it uses **Option**.

## Playback

| Action | Mac | Windows |
|---|---|---|
| Play or pause | Space | Space |
| Move the playhead back or forward a little | ← or → | ← or → |
| Step one frame while paused | , or . | , or . |
| Go to the beginning | Home | Home |
| Full-screen preview | F | F |
| Exit full screen | Esc | Esc |
| Mute the preview | M | M |
| Preview volume up or down | Option+↑ or Option+↓ | Alt+↑ or Alt+↓ |

## Editing

| Action | Mac | Windows |
|---|---|---|
| Undo | Cmd+Z | Ctrl+Z |
| Redo | Cmd+Shift+Z or Cmd+Y | Ctrl+Shift+Z or Ctrl+Y |
| Split at the playhead | Cmd+B | Ctrl+B |
| Delete selected clips, or cut selected transcript words | Delete or Backspace | Delete or Backspace |
| Copy or paste clips | Cmd+C or Cmd+V | Ctrl+C or Ctrl+V |
| Select all clips, or all words in a transcript block | Cmd+A | Ctrl+A |
| Clear the selection | Esc | Esc |

## Timeline view

| Action | Mac | Windows |
|---|---|---|
| Zoom in or out | Cmd+Plus or Cmd+Minus | Ctrl+Plus or Ctrl+Minus |
| Fit the whole edit in view | Shift+Z | Shift+Z |
| Move the view left or right | Shift+← or Shift+→ | Shift+← or Shift+→ |

## Projects and tabs

| Action | Mac | Windows |
|---|---|---|
| New project | Cmd+N | Ctrl+N |
| Open project | Cmd+O | Ctrl+O |
| Save | Cmd+S | Ctrl+S |
| Import media | Cmd+I | Ctrl+I |
| Close tab | Cmd+W | Ctrl+W |
| Reopen closed tab | Cmd+Shift+T | Ctrl+Shift+T |
| Next or previous tab | Ctrl+Tab or Ctrl+Shift+Tab | Ctrl+Tab or Ctrl+Shift+Tab |
| Go to tab 1 to 8, or the last tab | Cmd+1 to Cmd+8, Cmd+9 | Ctrl+1 to Ctrl+8, Ctrl+9 |
| Quit | Cmd+Q | Ctrl+Q |

## AI chat

| Action | Mac | Windows |
|---|---|---|
| Show or hide the chat | Cmd+L | Ctrl+L |
| Stop the AI (while typing in the chat box) | Esc | Esc |
| Mention a file from your library | @ | @ |

## Mouse

| Action | How |
|---|---|
| Move a clip without snapping | Hold Option (Alt) while dragging |
| Zoom the timeline | Cmd (Ctrl) plus scroll |
| Scroll the timeline left or right | Shift plus scroll |
| Fine-tune a volume line | Hold Shift while dragging |
| Rotate freely in the preview | Hold Shift while rotating |
| Add a point on a volume line | Cmd-click (Ctrl-click) the line |
