To reuse a caption style or a graphic in Daydream, ask the AI to save it ("save this caption style as Bold Yellow"). It goes into your **Memory** panel, and any project can use it after that.

## Save a caption style

Once your captions look the way you want:

> Save this caption style as Bold Yellow.

To use it in another project:

> Use my Bold Yellow captions.

Or open **Memory**, go to **Captions**, and apply it from there. Every caption in the project switches to the saved style.

## Save a graphic

> Save this lower third as "Name tag".

> Save the outro so I can use it on future videos.

To use it later:

> Add my Name tag lower third when I first appear, with "Sam Lee, Head of Product".

Or open **Memory**, go to **Graphics**, and drag it onto the timeline.

A saved graphic is a copy of the original, text included. When the AI adds it to a new video, it updates the text for that video. The saved version doesn't change.

{/* Visual: still of the Memory panel's Graphics tab with a few saved graphics */}

### Graphics with images

Logos and screenshots inside a graphic are saved with it. Daydream keeps a link to the image file rather than a copy, so don't move or delete those files. If one goes missing, Daydream warns you, and the graphic can't be added until the image is back or relinked.

Graphics that include your own video footage can't be saved.

## Use them automatically

Pair a saved style with a [preference](/automate/preferences) and you won't have to ask each time:

> From now on, always use my Bold Yellow captions.

Or bundle several together in a [recipe](/automate/recipes).

## Names

Use names you'll remember, in your own words. Saving with a name that's already taken asks before replacing the old one.

## How many can I save?

| Plan | Saved caption styles and graphics |
|---|---|
| Free | Not included |
| Creator | 3 caption styles and 3 graphics |
| Pro | No plan limit (Daydream holds up to 20 caption styles and 30 graphics) |

On plans that don't include it, the **Captions** and **Graphics** tabs in **Memory** show a lock. See [plans and limits](/help/plans-and-limits).
